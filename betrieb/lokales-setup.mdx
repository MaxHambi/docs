Der Lagerplatz-Barcode-Generator läuft als Web-App vollständig im Browser – keine serverseitige Logik, keine Datenübertragung. Du kannst das gehostete Live-Tool auf GitHub Pages verwenden oder die App bei Bedarf lokal betreiben. Beide Varianten sind im Folgenden beschrieben.

<Tabs>
  <Tab title="Variante 1 – Live-Tool (ohne Installation)">
    Die einfachste Möglichkeit: Öffne die Web-App direkt auf GitHub Pages, gib das Passwort ein und leg sofort los. Eine Installation ist nicht nötig.

    **URL:** [https://maxhambi.github.io/Lager-etiket/](https://maxhambi.github.io/Lager-etiket/)

    <Tip>
      Diese Variante eignet sich für den täglichen Einsatz. Da die App komplett im Browser läuft, funktioniert sie auch offline – nach dem ersten Laden der Seite.
    </Tip>
  </Tab>

  <Tab title="Variante 2 – Lokal betreiben">
    Wenn du die App auf einem eigenen Rechner oder in einem internen Netzwerk betreiben möchtest, richtest du einen lokalen statischen Server ein. Da die App zu 100 % im Browser läuft, ist kein Backend erforderlich.

    ### Voraussetzungen

    Stelle sicher, dass folgende Software installiert ist:

    - **Node.js 24** oder neuer – [nodejs.org](https://nodejs.org/)
    - **pnpm** – entweder über `npm install -g pnpm` oder über [corepack](https://nodejs.org/api/corepack.html)

    ### Einrichtung

    <Steps>
      <Step title="Repository klonen und Abhängigkeiten installieren">
        Klone das Repository und installiere alle Pakete:

        ```shell
        git clone https://github.com/MaxHambi/Lager-etiket.git
        cd Lager-etiket
        npm install -g pnpm    # falls pnpm noch nicht vorhanden ist
        pnpm install
        pnpm build
        ```
      </Step>

      <Step title="Statischen Server starten">
        Starte einen Server im gebauten Web-Paket. Du hast zwei Möglichkeiten:

        ```shell
        npx serve apps/web
        ```

        Oder alternativ mit Python:

        ```shell
        python -m http.server 8080 --directory apps/web
        ```
      </Step>

      <Step title="Im Browser öffnen">
        Öffne die angezeigte Adresse im Browser – standardmäßig `http://localhost:3000` bei `serve` bzw. `http://localhost:8080` bei Python.

        <Warning>
          Die App muss zwingend über `http://…` geladen werden. Öffnest du die Dateien direkt über `file://`, blockiert der Browser das Laden von Vorlagen und Konfigurationsdateien.
        </Warning>
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Nächste Schritte

Nach dem Setup kannst du direkt loslegen:

- **Schnellstart** – Erste Etiketten in wenigen Minuten erzeugen
- **Vorlagen und Einträge** – Eigene Layoutvorlagen anlegen und verwalten
- **Konfiguration** – Barcode-Aussehen und Ausgabeeinstellungen anpassen
