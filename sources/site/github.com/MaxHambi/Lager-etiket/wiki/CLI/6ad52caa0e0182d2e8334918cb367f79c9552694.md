# CLI

[Permalink: CLI](https://github.com/MaxHambi/Lager-etiket/wiki/CLI/6ad52caa0e0182d2e8334918cb367f79c9552694#cli)

Die Kommandozeilen-Erzeugung ist für alle gedacht, die Schilder in Skripte oder Automatisierung einbinden wollen — z. B. nächtliche Läufe über eine Eintragsliste oder Anbindung an ein Warenwirtschaftssystem.

## Voraussetzungen

[Permalink: Voraussetzungen](https://github.com/MaxHambi/Lager-etiket/wiki/CLI/6ad52caa0e0182d2e8334918cb367f79c9552694#voraussetzungen)

- **Node.js 24 oder neuer** ([nodejs.org](https://nodejs.org/))
- Ein Klon dieses Repositories (die CLI ist Teil des Monorepos)

Details zum Einrichten: [Lokales Setup](https://github.com/MaxHambi/Lager-etiket/wiki/Lokales-Setup).

## Installation

[Permalink: Installation](https://github.com/MaxHambi/Lager-etiket/wiki/CLI/6ad52caa0e0182d2e8334918cb367f79c9552694#installation)

```shell
git clone https://github.com/MaxHambi/Lager-etiket.git
cd Lager-etiket
npm install -g pnpm     # falls pnpm fehlt
pnpm install
pnpm build
```

Danach ist die CLI unter `packages/cli` gebaut. Sie heißt **`lager`**.

## `lager generate` — Schilder erzeugen

[Permalink: lager generate — Schilder erzeugen](https://github.com/MaxHambi/Lager-etiket/wiki/CLI/6ad52caa0e0182d2e8334918cb367f79c9552694#lager-generate--schilder-erzeugen)

Einzelner Lagerplatz:

```shell
node packages/cli/dist/cli.mjs generate 01A01 --out output
```

Ein Bereich (`--start` + `--end`, gleiche Präfix-Länge):

```shell
node packages/cli/dist/cli.mjs generate --start 01A01 --end 01A12 --out output
```

Eine Liste (eine Zeile pro Code, `#`\-Zeilen werden übersprungen):

```shell
node packages/cli/dist/cli.mjs generate --file liste.txt --out output
```

### Optionen

[Permalink: Optionen](https://github.com/MaxHambi/Lager-etiket/wiki/CLI/6ad52caa0e0182d2e8334918cb367f79c9552694#optionen)

| Option | Pflicht | Beschreibung |
| --- | --- | --- |
| `entry` (positionell) | eine Quelle | einzelner Lagerplatz, z. B. `01A01` |
| `--start` / `--end` | eine Quelle | Bereich, z. B. `01A01` bis `01A12` |
| `--file` | eine Quelle | Pfad zu einer .txt-Eintragsliste |
| `--config` | nein | Pfad zur config.json (sonst Standard-Config) |
| `--template` | nein | Pfad zur Vorlagen-PNG |
| `--out` | ja | Ausgabedatei oder -ordner (Default: `output`) |

Jede erzeugte Datei wird mit Namen und Größe gemeldet; am Ende steht `Fertig. N von N Schildern in <Ordner>`.

## `lager validate` — Codes prüfen

[Permalink: lager validate — Codes prüfen](https://github.com/MaxHambi/Lager-etiket/wiki/CLI/6ad52caa0e0182d2e8334918cb367f79c9552694#lager-validate--codes-pr%C3%BCfen)

Prüft Einträge auf Code-128-Kodierbarkeit und Duplikate, **ohne** zu rendern — ideal vor großen Läufen:

```shell
node packages/cli/dist/cli.mjs validate 01A01
node packages/cli/dist/cli.mjs validate --file liste.txt
```

Ausgabe pro Zeile: `OK 01A01` oder `INVALID 01A01 — Zeichen an Position …`. Zusammenfassung am Ende; bei ungültigen Codes ist der Exit-Code 1 (praktisch für Skripte).

## `lager list` — Formate anzeigen

[Permalink: lager list — Formate anzeigen](https://github.com/MaxHambi/Lager-etiket/wiki/CLI/6ad52caa0e0182d2e8334918cb367f79c9552694#lager-list--formate-anzeigen)

```shell
node packages/cli/dist/cli.mjs list
```

Zeigt die unterstützten Symbologien (primär Code 128 im Lager, weitere via etiket) und die aktuelle Konfigurationsquelle.

## Tipps

[Permalink: Tipps](https://github.com/MaxHambi/Lager-etiket/wiki/CLI/6ad52caa0e0182d2e8334918cb367f79c9552694#tipps)

- **Exit-Codes beachten:** 0 = alles gültig, 1 = ungültige Einträge oder Abbruch — perfekt für `if`\-Checks in Batch-/PowerShell-Skripten.
- **Erst prüfen, dann erzeugen:** `validate --file` vor dem großen `generate --file`\-Lauf spart Zeit.
- Die CLI nutzt dieselbe **Standard-Config** wie die Web-App ([Konfiguration](https://github.com/MaxHambi/Lager-etiket/wiki/Konfiguration)); eigene Pfade per `--config`.
- Ungültige Zeichen (z. B. Umlaute) werden **vor** dem Rendern abgelehnt — es entstehen keine halben Schilder.
